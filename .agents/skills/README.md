# Skills del proyecto

Instaladas y leídas para el ajuste móvil de Prompt Quest:

| Skill | Fuente oficial | Uso |
| --- | --- | --- |
| frontend-design | https://github.com/anthropics/skills/tree/main/skills/frontend-design | Composición, jerarquía y aplicación del estilo terminal existente. |
| accessibility-review | https://github.com/anthropics/knowledge-work-plugins/tree/main/design/skills/accessibility-review | Controles de 44 px, contraste, teclado, zoom y semántica. |
| design-critique | https://github.com/anthropics/knowledge-work-plugins/tree/main/design/skills/design-critique | Revisión del recorrido encargo → editor → ejecutar y de los resultados. |

Las skills se conservan en sus respectivas carpetas con su contenido original. Codex puede descubrirlas en los siguientes turnos; en este trabajo se leyeron expresamente desde el disco antes de editar el frontend.

`modern-web-guidance` se instaló como consulta auxiliar desde https://github.com/GoogleChrome/modern-web-guidance/tree/main/skills/modern-web-guidance para cumplir el router local. Su biblioteca completa queda ignorada por Git. Se consultaron `responsive-design`, `form-factor-adaptation` y `accessibility`.
